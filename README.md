## 1. Project Overview

This project folder contains the planning documents and is intended to contain the future source code for the Global Education & Careers website.

Global Education & Careers is a proposed overseas education and career-guidance organisation based in Hyderabad, Telangana, India.

The website is intended to support:

- Students
- Parents
- Working professionals
- Corporate professionals
- University representatives
- Academic institutions
- Training organisations

The proposed website will present GEC’s services, study destinations, academic programs, resources, counselling options, university-partnership opportunities, and contact information.

The website will also include private administrative tools for managing enquiries, appointments, follow-ups, content, and institutional enquiries.
