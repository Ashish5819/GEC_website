## 1. Purpose of This Sitemap

This document defines the proposed structure of the Global Education & Careers website.

It describes:

- Main navigation
- Dropdown menus
- Public pages
- Country pages
- Service pages
- Program pages
- Resource pages
- Counselling and contact pages
- University partnership pages
- Legal pages
- Administrative pages
- Important user journeys
- Internal linking relationships

The sitemap should be treated as the structural plan for the website before design and coding begin.

---

## 2. Primary Website Navigation

The main desktop navigation should contain:

1. Home
2. About GEC
3. Study Abroad
4. Programs
5. Services
6. University Partnerships
7. Resources
8. Contact
9. Book Counselling

The “Book Counselling” item should appear as a highlighted button.

On mobile devices, the same navigation should appear inside a collapsible menu.
