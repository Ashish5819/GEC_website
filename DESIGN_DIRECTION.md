## 2. Overall Design Goal

The GEC website should appear:

- Professional
- Academic
- Trustworthy
- International
- Modern
- Student-focused
- Parent-friendly
- Clear
- Calm
- Premium without appearing expensive
- Informative without appearing crowded
- Supportive without appearing informal
- Credible without relying on exaggerated claims

The design should communicate that GEC is a serious overseas education and career-guidance organisation.

The design should not resemble a generic template or a copied consultancy website.

---

## 3. Brand Personality

The proposed GEC brand personality should combine:

### Academic Credibility

The website should feel connected to education, universities, career planning, and professional guidance.

### Global Outlook

The design should reflect international opportunity, movement, cultural diversity, and global education.

### Personal Support

The interface should feel approachable and supportive for students and families.

### Ethical Guidance

The website should visually support transparency and careful decision-making rather than guaranteed outcomes.

### Modern Professionalism

The website should look current and polished while remaining easy to understand.

## 7. Colour Accessibility Rules

The website must:

- Maintain sufficient contrast between text and background
- Avoid light grey text on white backgrounds
- Avoid gold text for paragraph content
- Avoid using colour as the only indicator of status
- Pair status colours with icons and text labels
- Use visible keyboard focus outlines
- Test buttons and links for accessibility
- Support users with colour-vision differences

Primary text should remain dark enough for long-form reading.

## 10. Typography Rules

The website should:

- Use one heading family and one body family
- Avoid more than three font weights per family
- Use line heights suitable for long reading
- Limit paragraph width
- Avoid all-capital paragraphs
- Avoid overly bold body text
- Use bold text only for meaningful emphasis
- Maintain consistent heading levels
- Keep links visually identifiable

Suggested paragraph line height:

1.7 (D)

Suggested maximum reading width:

72 characters per line (D)

## 46. Accessibility Direction

The website should aim to meet WCAG 2.2 AA requirements. (D)

Required accessibility features:

- Semantic headings
- Keyboard navigation
- Visible focus states
- Descriptive links
- Form labels
- Error descriptions
- Alternative text
- Sufficient contrast
- Reduced-motion support
- Accessible dropdowns
- Accessible accordions
- Accessible modal dialogs
- Skip-to-content link
- Logical reading order
- Screen-reader-friendly status messages

No important interaction should depend only on hover.

---

## 47. Form Accessibility
